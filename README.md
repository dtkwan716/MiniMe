# MiniMe

A small animated desktop companion built with Python and PySide6. MiniMe stays on top of other windows with a transparent background, keeping you company while you use your computer.

## Features

- Walks around your screen
- Idle animations: eating, hearts, and waving
- Drag-and-drop interactions
- Hit reactions
- Falling animation with balloons you can pop
- Automatically sleeps when your mouse is inactive
- Work mode with a stopwatch

## Built With

- Python
- PySide6
- PyInstaller for executable packaging

## Running MiniMe

Download the packaged application, extract the files, and launch the executable.

## About

I built MiniMe to practice desktop GUI development, mouse event handling, timers, and coordinating animations with different character behaviors.
